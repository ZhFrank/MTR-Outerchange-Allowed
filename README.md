# MTR-Outerchange-Allowed
An addon for the [Minecraft Transit Railway](https://modrinth.com/mod/minecraft-transit-railway) mod that allows outerchanges through ticket barriers.
[我的世界铁路](https://modrinth.com/mod/minecraft-transit-railway)的附属模组，允许玩家通过闸机进行出站换乘。

# Crucial Info 重要信息
## Requirements 前置
- Minecraft Transit Railway 4.0 or higher version is REQUIRED.
- Minecraft Transit Railway 4.0 或更高版本是必要前置。
- (Only Fabric) Fabric API is REQUIRED.
- （仅针对Fabric版本）Fabric API 是必要前置。
## Supported Environment 运行环境
- Personal saves must be installed.
- 个人存档必须安装。
- For Servers: 对于服务器：
-- For servers already installed this mod, players who want to modify the outerchange configuration file of the ticket barriers must have this mod installed on their client; if you just want to experience ticket barriers set up by others on the server, installing it on the client is optional.
-- 对于已安装本mod服务器，想要修改闸机的出站换乘配置文件的玩家务必在客户端安装本mod；如果您只是想在服务器中体验他人设置好的闸机，则客户端的安装是可选的。
